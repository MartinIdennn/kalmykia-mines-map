# Рудники Калмыкии — карта и сбор донатов (MVP)

Интерактивная карта Калмыкии с метками рудников/месторождений. По клику на метку открывается
панель с описанием, галереей фото, сметой (на что идут деньги), прогрессом сбора и формой доната.
Донатеры отображаются вживую.

> ⚠️ **Прототип.** Донаты — **заглушка**: реальные платежи не принимаются, суммы/донатеры/фото —
> демонстрационные. Координаты рудников реальные, но описания и сметы вымышлены для демо.

## Стек
- **Фронтенд (то, что хостится):** vanilla HTML/JS + [Leaflet](https://leafletjs.com/) + CartoDB/Esri тайлы.
  Данные рудников — статический `public/data/mines.json`; донаты сохраняются в браузере (localStorage).
- **Бэкенд (для разработки данных):** Node.js + Express + SQLite — генерирует `mines.json` через сид/экспорт.

> На GitHub Pages работает только статика, поэтому донаты на сайте хранятся локально в браузере
> посетителя (демонстрация UX), а не на сервере.

## Запуск

**Онлайн (статика, GitHub Pages):** просто открыть страницу — данные грузятся из `data/mines.json`.

**Локально с генерацией данных:**
```bash
npm install      # зависимости
npm run build    # пересоздать БД и экспортировать public/data/mines.json
npm start        # сервер со статикой на http://localhost:3000
```
Порт меняется через `PORT` (например `PORT=3001 npm start`).

## Структура

```
server/
  db.js              SQLite + схема
  seed.js            демо-данные (9 рудников Калмыкии), фото — loremflickr
  export-static.js   БД → public/data/mines.json
  index.js           Express: раздача статики (+ старое API для совместимости)
public/
  index.html         карта + панель рудника
  app.js             Leaflet, статические данные, донаты в localStorage
  styles.css         адаптивная вёрстка, маркеры-пины
  data/mines.json    запечённые данные рудников (источник правды для сайта)
  kalmykia.geojson         граница Калмыкии (маска вокруг)
  chernye-zemli.geojson    граница заповедника «Чёрные земли»
```

## Карта
- Слои: **Спутник** (Esri, по умолчанию) и **Схема** (CartoDB Voyager) — переключатель справа.
- Граница Калмыкии с затемнением всего вокруг; обзор заперт в пределах региона.
- Заповедник «Чёрные земли» (степной участок) — зелёная обводка с описанием по клику.
- Подписи районных центров и сёл.

## Данные (демо)
9 точек Калмыкии (Каспийское, Цаган-Аман, Состинское, Городовиковск, Элиста, Яшкуль, Приютное,
Ики-Бурул, Олейниковское). Координаты реальные; **суммы, сметы, донатеры и фото — вымышленные/случайные**.

## Известные ограничения (MVP)
- Донаты не подключены к платёжному провайдеру — это заглушка для демонстрации UX.
- Порядок демо-донатеров в сиде сортируется по id, а не строго по времени (косметика; на живых донатах корректно).
- Для боевого приёма денег потребуются: платёжный провайдер (ЮKassa/CloudPayments), юрлицо/самозанятость,
  договор-оферта, согласие на обработку ПДн, аутентификация и защита API.
